Questions

InstantBot FAQ

Something missing? Ask us on Discord - we answer fast.

Do I need to know how to code?
No. Modules are switched on and configured with forms, and custom commands are built by connecting blocks in the visual builder.
Will the bot have my own name and avatar?
Yes. InstantBot runs on your own Discord application, so it carries your name, avatar, banner, About me and status - and can have a different nickname and picture on each server.
Can I use it on several servers?
Yes. We set no server limit. Every server gets its own modules, flows and settings, and you switch between them in the panel. Discord itself requires bot verification above 100 servers.
Can it talk to other services?
Yes. The Web request block calls any API or webhook (GET, POST, PUT, PATCH, DELETE) with custom headers and a JSON, text or form body. Secret headers are never shown again after saving.
What's the difference to Discord bot hosting?
With Discord bot hosting (from €0.90/mo) you upload and run your own code. InstantBot is a finished bot that we maintain - you only configure it.
How can I pay?
You top up your InstantNode balance via PayPal, credit card or cryptocurrency - all services are then paid from that prepaid balance. Billing is monthly and you can cancel at any time.
